# Карта модулей content-скрипта

Все файлы работают как один скрипт (общий контекст): функции и константы из других модулей доступны напрямую.
Порядок подключения важен (он такой же, как в таблице). Присылайте мне только тот модуль, в котором проблема,
и текст ошибки / строки из консоли. Верну модуль целиком.

| Модуль | Что внутри | Присылать, когда |
|---|---|---|
| `00_config.js` | Константы: тексты и варианты сообщений, паузы, лимит в день, ВСЕ селекторы Bitrix/WhatsApp, настройки, общие переменные | поменять тексты/паузы/лимит; сломался селектор (кнопка, поле, колонка) |
| `01_utils.js` | Общие утилиты: sleep, поиск элементов в том числе в iframe, Escape, клики, уведомления, варианты текстов, дневной лимит, даты | общие функции ведут себя странно |
| `10_bitrix_queue.js` | Очередь заявок: обход колонки, выбор следующей карточки, пропущенные заявки, пауза между клиентами, режим «снизу вверх» | плагин не берёт/зацикливается на заявках, не работает порядок или фильтр дат |
| `11_bitrix_messenger.js` | Мессенджер Bitrix: «Чат» → «Ответить»/«Присоединиться», закрытие карточки через Escape | проблемы с мессенджером, кнопкой «Ответить», закрытием карточки/модалок |
| `12_bitrix_stage.js` | Смена стадии: кнопка стадии, окно с обязательными полями, «Источник», «Сохранить», выпадающие списки | не меняется статус, не заполняется окно со стадией |
| `20_wa_search.js` | WhatsApp: поиск номера через «Новый чат», выбор результата, пропуск заявки | не находит номер / не кликает на результат поиска |
| `21_wa_chat.js` | WhatsApp: анализ переписки (что делать с чатом), правила 1 касание, разбор сообщений и дат | неправильные решения «писать / пропустить», не определяет даты или ответы |
| `22_wa_send.js` | WhatsApp: отправка текста и PDF-файла | не отправляется текст или файл в WhatsApp |
| `30_bitrix_chat_sender.js` | Ctrl+Alt+Enter: отправка двух сообщений и файла в чат Bitrix (Instagram) | проблемы с отправкой в чат Bitrix |
| `99_main.js` | Точка входа: приём команд от popup/background, горячие клавиши Ctrl+Shift+X / Ctrl+Shift+Z | не работают STOP/старт/возобновление |

## Зависимости (если правка затрагивает несколько модулей, пришлите их все)

- Любой модуль использует `00_config.js` (константы) и `01_utils.js` (утилиты).
- `10_bitrix_queue.js` → `11_bitrix_messenger.js`, `12_bitrix_stage.js`, `20_wa_search.js` (через background).
- `20_wa_search.js` → `21_wa_chat.js` → `22_wa_send.js`.
- `99_main.js` вызывает функции остальных модулей.
